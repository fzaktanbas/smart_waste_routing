# Smart Waste Routing

## Akıllı Çöp Toplama Rota Optimizasyon Sistemi

Belediyelerin çöp toplama operasyonlarını optimize etmek amacıyla
geliştirilen bir yazılım projesidir.

### Projenin Amacı

Sistem; çöp konteynerlerinin doluluk durumlarını, konumlarını
ve belediye araçlarının kapasitelerini kullanarak uygun toplama
rotaları oluşturmayı amaçlamaktadır.

### Planlanan Özellikler

- Konteyner yönetimi
- Belediye araç yönetimi
- Konteyner doluluk takibi
- Harita tabanlı görüntüleme
- Rota oluşturma
- Çoklu araç rota optimizasyonu
- Dashboard ve istatistikler
- Kullanıcı yetkilendirme
- Performans karşılaştırmaları
